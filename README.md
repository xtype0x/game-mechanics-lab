# Gacha Game Tool

給台灣小型遊戲開發者的**遊戲機制模擬主控台**：瀏覽機制 → 組合 → 調整參數 → 模擬比較 → 試玩 → 匯出。

目前進度：**M5 完成**（傷害機制、回合戰鬥模擬、內容編輯器、A/B 比較、可試玩 2D DEMO），戰鬥規則 0.8。完整路線見 [docs/PLAN.md](docs/PLAN.md)。

## 立即使用
- 免安裝：直接用瀏覽器開啟 `packages/console/dist/index.html`（建置後產生，可離線）。
- 開發模式：
  ```bash
  npm install
  npm run dev
  ```

## 目前可用的工具
| 工具 | 做什麼 |
|---|---|
| 傷害計算與分項檢視 | 輸入攻守雙方與技能，逐乘區展開每個數字的來源；A/B 兩方案比較 |
| 乘區組合器 | 勾選機制元件、改寫公式、新增自訂乘區與自訂數值，即時檢查相容性 |
| 暴擊分布分析 | 多段命中的總傷害精確分布、門檻機率，以及抽樣對照 |
| 速度與行動順序模擬器 | 調整速度，即時看到各輪的行動時間軸 |
| 技能資源與能量模擬器 | 自動打一場，看能量累積曲線與大招時機；多場平均 |
| 弱點削韌與擊破模擬器 | 敵人韌性曲線、擊破次數、首次擊破時間與擊破傷害 |
| 狀態效果與結算編輯器 | 增減益、控制、持續傷害、護盾、復活、支配、條件式修正；試算持續傷害每跳數值 |
| 角色數值與職能編輯器 | 新增、複製、編輯我方與敵方角色；屬性抗性、狀態抵抗、階段、行動條事件 |
| 技能與目標規則編輯器 | 用表單組合技能效果（傷害、治療、狀態、召喚、驅散、計數器、插隊行動…）與被動追加攻擊 |
| 敵人 AI 規則編輯器 | 條件＋權重的行動規則；預覽不同血量與回合下的技能機率 |
| 戰鬥情境與關卡編輯器 | 敵人站位、戰鬥規則、弱點覆蓋檢查與快速試跑 |
| 單場逐步執行與重播 | 親手或自動一步步打一場戰鬥，可退回上一步，查看完整戰鬥紀錄，並在 DEMO 畫面中重播 |
| 批量戰鬥模擬 | 跑數百場統計勝率、輪數、傷害來源；設定基準比較兩種方案 |
| A/B 方案比較 | 存快照後修改，用相同種子比較兩版的勝率、傷害與設定差異 |
| 內容相依關係總覽 | 誰使用了哪個技能、狀態、角色；標出失效引用與未使用內容 |
| 參考資料匯入（實驗中） | 開啟自己蒐集的參考資料包，換算等級數值後匯入成角色（只供本機研究） |

所有編輯器底部常駐「快速驗證」列：每次修改後自動試跑目前的戰鬥，顯示勝率、輪數與錯誤，可釘選基準比較差異。

「新專案」可選擇「弱點擊破型回合制」、「基礎回合制」或「首領機制型」範本。所有編輯都會即時驗證，資料有錯誤時模擬器會說明原因而不會執行。

戰鬥直接使用「乘區組合器」中的傷害公式：改公式後重跑批量模擬，就能看到對整場戰鬥的影響。

## 試玩 DEMO
主控台右上角「▶ 試玩 DEMO」用**目前專案**的角色、技能與規則開一個可玩的 2D 回合制小遊戲，證明主控台調出來的機制能直接變成成品。

- **內容**：3 個關卡（含多波與首領戰）、編隊、角色升級、獎勵結算，以及簡易召喚（5★ 機率 2%、第 50 抽保底）。
- **戰鬥畫面**：程序繪製的角色與演出，顯示行動順序、生命／韌性／能量、技能點、擊破、大招特寫；可切換 AUTO、倍速與跳過。動畫只影響時間，**不影響規則與結果**。
- **與主控台雙向連結**：DEMO 內「⚙ 調整數值」直接改寫專案；主控台「單場逐步執行」可「在 DEMO 中重播」任一場戰鬥。
- **單檔匯出**：在建置後的 `dist/index.html` 中按「匯出試玩 DEMO」，得到一個內含專案資料的獨立 HTML，可離線、直接用瀏覽器開啟或分享。
- **存檔**：進度存在瀏覽器（localStorage），重新開啟會接續。
- **裝置**：畫面為 16:9，桌面與橫放的手機都可玩；手機直拿時畫面會自動轉 90°，請橫放手機觀看。系統開啟「減少動態效果」時，待機動畫與粒子特效會關閉。

DEMO 中的角色、敵人、關卡與數值都是本工具的原創範例，可在主控台自由修改。

## 給其他引擎／語言的開發者
核心規則有完整規格（[docs/spec](docs/spec/README.md)）與語言無關的測試向量（`packages/core/vectors/`）。
在 Unity（C#）、Godot、伺服器等環境重新實作時，跑完全部向量即可確認結果與本工具一致。
