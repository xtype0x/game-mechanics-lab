# 二遊官網致敬版

這是本機原型。完整計畫動機已放入關於計畫頁，入口為 `#/about`。

## 視覺方向

- 原創二遊主視覺、深藍與青金色、超大標題、宣傳官網式導覽及裝備選單。
- 諷刺放在救世宣傳與實際研究工具的落差：改寫世界參數、從暴擊率開始的史詩冒險、沒有預約獎勵。
- 圖中的角色手持游標卡尺與遊戲手把，將玩家和開發者變成主角。
- 「立即開玩」實際進入工具遊樂場，只有可用工具有可點擊入口。
- 未加入虛構預約人數、獎項、倒數、下載數或不存在的宣傳影片。

風格參考：常見二遊宣傳官網的敘事形式，可參照 [絕區零](https://zenless.hoyoverse.com/en-us/main) 與 [鳴潮](https://wutheringwaves.kurogames.com/jp/)。本頁使用原創圖像，沒有沿用其角色、商標或網站素材。
