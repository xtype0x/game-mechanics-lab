# 核心規格（v0.5.0，戰鬥規則 0.8.0，抽卡規則 1.0.0）

這些文件是 `packages/core` 的**權威規格**。任何語言的移植版本必須依此實作，並通過 `packages/core/vectors/` 的全部測試向量。
若程式行為與規格不一致，視為程式錯誤。

| [rng.md](rng.md) | 亂數產生器與亂數流 |
| [expr.md](expr.md) | 規則表示式樹 |
| [damage.md](damage.md) | 修正值模型、傷害管線、暴擊分布、相容性 |
| [battle.md](battle.md) | 回合戰鬥：行動值、技能、削韌、狀態、AI、自動策略；§13 擴充機制（抗性、嘲諷、護盾、復活、驅散、召喚、階段、計數器、插隊行動、引爆）；§14 觸發對象條件、隊友命中觸發、支配、行動條事件；§15 條件式修正、受控判負、依目標生命的傷害 |
| [gacha.md](gacha.md) | 抽卡：稀有度、軟／硬保底、限定與大保底、單抽規則、抽數分布、長期機率、機率公示 |
