# 規則表示式規格

規則中的公式與條件以 JSON 樹保存，**不得**保存或執行任意程式碼。

## 1. 節點
| 節點 | 形式 |
|---|---|
| 常數 | `{"const": number \| boolean \| string}` |
| 變數 | `{"ref": "attacker.atk"}`，名稱為以 `.` 分隔的識別字 |
| 運算 | `{"op": "<名稱>", "args": [節點...]}` |

## 2. 運算子
| op | 參數 | 結果 | 文字寫法 |
|---|---|---|---|
| add, sub, mul, div | 2 | 數值 | `+ - * /`；div 除以零為錯誤 |
| neg | 1 | 數值 | `-x` |
| gt, gte, lt, lte | 2 | 布林 | `> >= < <=` |
| eq, neq | 2 | 布林 | `== !=`；嚴格相等，不轉型 |
| and, or | 2 | 布林 | `&& \|\|`；短路求值 |
| not | 1 | 布林 | `!x` |
| min, max | ≥1 | 數值 | 函式 |
| clamp(x, lo, hi) | 3 | 數值 | `min(max(x, lo), hi)` |
| floor, ceil, round, abs | 1 | 數值 | round 依 numeric.md 的半數遠離零 |
| if(cond, a, b) | 3 | a 或 b | 只求值被選中的分支 |

## 3. 型別轉換
- 需要數值時：布林 true → 1、false → 0；字串為錯誤。
- 需要布林時：數值非 0 為真；字串非空為真。
- 未定義的變數為錯誤。
- 大小比較（gt/gte/lt/lte）只接受數值或布林；字串為錯誤。
- `eq`／`neq` 不轉型：`1 == true` 為假，`"1" == 1` 為假。
- `if` 原樣回傳被選分支的值（可以是字串或布林）。
- `neg`、`abs` 不做 -0 正規化（-0 與 0 比較相等，JSON 輸出皆為 0）；只有取整會正規化。
- 運算節點的參數數量不符時，專案檔驗證失敗。

## 4. 文字語法（編輯器用）
優先序由低到高：`||` < `&&` < 比較 < `+ -` < `* /` < 一元 `- !`。二元運算皆左結合。
數字可寫 `50%`，代表 0.5。字串用單或雙引號。`true`、`false` 為布林常數。

詞法：
- 數字：`d+(.d*)?|.d+`，可接 `[eE][+-]?d+`，可接 `%`。
- 識別字：`[A-Za-z_]w*(.[A-Za-z_]w*)*`（含點，整串視為一個變數名稱）。
- 字串：從引號到下一個相同引號，**沒有跳脫字元**。
- 一元負號後接數字常數時直接折成負數常數；否則產生 `neg` 節點。
- 文字語法只是編輯介面；規格的權威形式是 JSON 樹。
