# 抽卡模擬器（@gml/gacha-sim）

固定規則範本與可自訂模型的抽卡實驗。抽數分布、保底、天井、定軌和花費計算都使用 `@gml/core` 的 `Gacha` 命名空間，規格見 `docs/spec/gacha2.md`。

```bash
npm run site:dev           # http://127.0.0.1:5180/gacha/
npm run site:build         # 一般網站建置
npm run site:build:offline # 單檔 apps/site/offline/gacha/index.html
```

## 固定通用卡池

2026-10-13 起不再讀取當前活動或角色名稱。即時來源、手動清單、快照、更新按鈕與抓取腳本已移除。選單按遊戲與卡池類型提供固定規則，物品使用「限定 5★ 角色」「常駐 5★ 角色」「UP 4★」等通用名稱。不同遊戲的稀有度與機制仍保留。

| 遊戲 | 規則範本 |
| --- | --- |
| 崩壞：星穹鐵道 | 限定角色、光錐、常駐 |
| 原神 | 限定角色、武器定軌、常駐 |
| 絕區零 | 獨家頻段、音擎頻段、常駐 |
| 蔚藍檔案 | 國際服天井兌換、日服累計保底 |
| 鳴潮 | 限定角色、限定武器、常駐 |
| 明日方舟：終末地 | 特許尋訪、基礎尋訪 |
| 異環 | 限定角色、常駐 |

規則參數在 `src/catalog/games.ts`，每個範本附來源與限制。它們是研究模型，不保證和最新正式服一致；軟保底部分取自社群推估。數值變更須另行核對來源。定軌武器池保留兩個通用目標 A/B；次高稀有度的 UP 與大保底不依賴任何角色清單。

## 中文與英文

`src/i18n/zh-Hant.ts` 與 `en.ts` 涵蓋抽卡畫面、動畫、分析設定、分享、統計、來源與驗證錯誤。模擬器有語言切換，沿用網站的語言偏好。英文文案配合版面編寫。

內建名稱在顯示時轉換，切換語言不更改儲存中的數值、模型 ID、物品 ID 或抽卡進度。不認得的使用者自訂名稱保留原文。核心套件仍保持純資料與規則，中文的核心驗證訊息由小專案於顯示時翻譯。

## 舊存檔相容

瀏覽器儲存鍵沿用 `ggt.gacha-sim.v1`、`ggt.gacha-sim.pulls.v1`、`ggt.gacha-sim.fast`。

- 未修改的舊遊戲卡池轉換為通用卡池，保留目標份數、保底計數、預算與儲值設定，指定目標會映射到通用物品。
- 已修改的模型與比較資料只移除舊活動名稱，保留數值規則與物品參照。
- 原抽卡紀錄沿用同一遊戲／類型的模型 ID；舊結果用通用名稱顯示。
- 舊 `ggt.gacha-sim.live.v1` 快取在開啟新版時清除，不再讀寫外部卡池資料。

## 分享與動畫

分享連結把規則與目標放在 `#rules=…`，不經過伺服器，載入前先顯示提示。匯出／匯入 `.gacha.json` 沿用 `ggt-gacha-rules` 格式，先做形狀與大小檢查，再由核心驗證規則；不包含抽卡進度、預算與儲值設定。

動畫使用 CSS，流星 → 高稀有度亮相 → 結果清單；不使用遊戲圖片。可以略過，或依「減少動態效果」設定直接顯示結果。

## 驗證

測試在 `test/`：固定卡池有效性與保證上限、機率檢查、四星 UP／定軌、舊存檔與比較資料轉換、分享格式、中英文佔位參數和完整名稱翻譯。根目錄 i18n guard 檢查 UI 字串只出現在字典。
