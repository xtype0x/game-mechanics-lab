# 抽卡模擬器（`@gml/gacha-sim`）

網站頁面 `gacha/`（見 [project.json](./project.json)）。

給一般玩家的抽卡模擬器。打開就是抽卡畫面；「設定與分析」可自由調整規則並精確計算抽數與花費。計算核心是 `@gml/core` 的 `Gacha` 命名空間（[規格](../../docs/spec/gacha2.md)）。

```bash
npm run site:dev           # http://127.0.0.1:5180/gacha/
npm run site:build:offline # 單檔 apps/site/offline/gacha/index.html
npm run gacha:snapshot     # 更新卡池快照
```

## 遊戲卡池與資料來源
一款遊戲一個按鈕，選單內選卡池類型與目前的卡池。

| 遊戲 | 卡池類型 | 目前卡池內容來源 |
|---|---|---|
| 崩壞：星穹鐵道 | 限定角色、光錐、常駐 | [api.ennead.cc](https://github.com/torikushiii/hoyoverse-api)（官方活動日曆，開源，免金鑰，每 IP 每秒 2 次） |
| 原神 | 限定角色、武器（定軌）、常駐 | 同上 |
| 絕區零 | 獨家頻段、音擎頻段、常駐 | 同上（同一期的兩個頻段拆成兩個卡池） |
| 蔚藍檔案 | 國際服 Pickup（天井兌換）、日服 Pickup（累計保底） | [SchaleDB](https://schaledb.com) 公開資料（`config.min.json`、`tw/students.min.json`）；**可能比遊戲晚更新**，畫面會顯示日期與「已結束」 |
| 鳴潮 | 角色活動、武器活動、常駐 | 找不到可從網頁讀取的公開資料，**手動清單** `src/catalog/manual.json` |
| 明日方舟：終末地 | 特許尋訪、基礎尋訪 | 手動清單；武器池（只能十連、來源矛盾）暫未收錄 |
| 異環 | 限定角色、常駐 | 手動清單；弧盤（武器）池暫未收錄 |

- **只有卡池內容（限定角色／武器名稱、日期）來自外部**；機率、保底等規則是穩定的遊戲機制，寫在 `src/catalog/games.ts`，每類都附來源與可信度說明（軟保底增幅是社群統計，官方未公布）。
- **載入順序**：先顯示 `src/catalog/snapshot.json`（離線也能用），再從來源抓即時資料取代；成功的結果在瀏覽器快取 30 分鐘。某個來源失敗時，該遊戲沿用快照。
- **手動清單**：`src/catalog/manual.json`，每個卡池一筆（遊戲、類型、5★／4★ 名稱、開始與結束時間〔ISO 格式，要帶時區，例如 `+08:00`〕、來源網址），另有 `updated` 日期顯示在選單底部。新一期開始時編輯它並重新 build；測試會檢查格式、時間與遊戲是否正確。過期的卡池會顯示「已結束」，不會壞掉。
- **更新快照**：`npm run gacha:snapshot` 執行與瀏覽器相同的抓取程式（`src/catalog/live.ts`），只有至少一個來源成功時才寫入。上線前或改版後執行一次即可。
- 官方只公布基礎機率與「綜合機率」時，軟保底的每抽增幅取能讓平均抽數符合綜合機率的值（絕區零音擎、鳴潮），測試會檢查。異環的「棋盤切換後機率跳到 19.59%」用軟保底上限（規則 2.2 的 `max`）表示。
- 不使用任何遊戲圖片；遊戲名稱與角色名稱只用於說明卡池內容。

## 分享規則
「設定與分析」的「分享與備份」：
- **複製分享連結**：規則與目標壓縮後放在網址的 `#rules=…`，不經過任何伺服器。對方打開時會先詢問是否載入，不會直接蓋掉他的設定；抽卡進度不受影響。
- **匯出／匯入檔案**：`.gacha.json`（`{format: "ggt-gacha-rules", version: 1, model, target}`，也接受單純的模型 JSON）。
- 外來的資料一律先檢查格式與大小（`src/share.ts`），再用 `Gacha.validateModel` 驗證，壞掉的連結或檔案只會顯示原因。

## 抽卡動畫
流星（顏色＝這次最好的結果：金／紫／藍）→ 每張最高稀有度的卡個別亮相 → 全部結果。全部用 CSS 畫，不使用任何遊戲素材。可點「略過」或勾「略過動畫」（記在瀏覽器）；系統設定「減少動態效果」時直接顯示結果。

## 來源與測試
2026-10-11 由 `packages/gacha-sim` 併入網站，同日再獨立成小專案 `projects/gacha-sim`。網站版多了 `?game=<id>` 預選；返回連結由網站從 `project.json` 傳入。測試在 `test/`（根目錄 `npm test` 會執行），快照腳本是 `scripts/update-snapshot.ts`。瀏覽器儲存鍵 `ggt.gacha-sim.*` 刻意沿用舊名，避免訪客設定失效。
