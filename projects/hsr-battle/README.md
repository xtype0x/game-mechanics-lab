# 星穹鐵道戰鬥研究室（`@gml/hsr-battle`）

網站頁面 `hsr/battle/`（設定見 [project.json](./project.json)）。原為網站內的「戰鬥實驗室」，2026-10-11 獨立成小專案。編輯器、模擬器與動畫戰鬥畫面來自共用的 `@gml/ui`，規則來自 `@gml/core`。動畫戰鬥畫面取自研究 repo 的試玩 DEMO，不含標題畫面、關卡、抽卡與升級。

```bash
npm run site:dev   # http://127.0.0.1:5180/hsr/battle/
```

## 內容
可選隊伍與敵人、改角色數值與技能、預覽行動順序、批量模擬勝率，並用動畫畫面開打。修改存在瀏覽器 localStorage；開啟「進階研究」，按彈窗底部「重設整個研究室」並確認後回到範本。

- **資料**：角色預設、敵人與裝備資料都來自共用套件 [`@gml/data-hsr`](../../packages/data-hsr/README.md)（資料來源、產生方式與限制也寫在那裡）。本專案只負責畫面與互動。
- **預設選單**：`src/presets/index.ts` 依序列出「星穹鐵道」（`@gml/data-hsr/presets`）與「範本角色」（`templates.ts`，原創角色）。預設只看可用角色，支援搜尋與篩選。
- **配裝面板**：`src/EquipPanel.tsx`。邏輯用 `@gml/data-hsr/equipment`，儲存用本專案的 `src/loadoutStorage.ts`。只套用無條件數值；條件效果只列出，尚未模擬。

## 角色介面與進階研究

側邊欄切換角色詳情、光錐、遺器、技能・行跡與隊伍・敵人；角色頭像可直接切換隊員。選好隊伍位置後，按隊伍名字下方或角色資訊上的「更換角色」即可開啟選單；編隊頁的每個位置也有獨立換人按鈕。常用數值提供快捷值、逐項恢復預設及輸出／輔助／擊破面板配置。角色詳情編輯配裝後的最終數值，會反推基礎值，避免重複套用裝備。低於裝備最低值的快捷選項會停用，整組配置也受相同下限約束。能量恢復效率以 100% 起算。

技能頁按普通攻擊、戰技、終結技與天賦・追擊分類，可快速設定數字倍率、削韌、技能點與能量；條件公式保留在進階研究。光錐提供快速選取與疊影，遺器提供通用配裝與主詞條快捷選取。

面板配置會保留未列出的其他數值，不是整張面板的重設。編輯器刻意固定深色，與動畫戰鬥畫面一致，不跟隨宿主網站的淺色模式。隊伍數值通常在修改後 400ms 自動存檔；頁面隱藏或離開時立即寫入尚未存檔的變更。

嘲諷、抗性覆寫、公式、被動觸發、行動順序、批量模擬與戰鬥規則，需按「進階研究」開啟彈窗。支援 Escape、背景點擊與關閉按鈕，沿用原本完整編輯器與存檔。手機版改為頂部角色列與可橫向捲動的分類。

## 裸裝試玩基準

`src/trialBalance.ts` 只調整本研究室的原創範本，不影響核心套件的示範戰鬥與匯入的鐵道資料。原創角色以相似定位的鐵道角色 Lv80 裸裝成長值作為生命、攻擊、防禦、速度與暴擊基準，移除預先灌入的配裝增傷、效果命中與擊破特攻；原創技能保留。

範本普通敵人的生命約 1,800～2,800、攻擊 160～190；灰燼巨像為生命 9,500、攻擊 250。弱點屬性抗性為 0，移除額外的固定 10% 減傷，保留韌性乘區。機制敵人的第二條血、召喚物也採試玩數值；夢鐘仍維持不可攻擊的事件。這些是裸裝試玩平衡值，不是正式服敵人數值。

「一鍵鐵道試玩」會換上姬子、丹恆、希露瓦、傑帕德，套用範本普通戰，並清除這四人的光錐與遺器（行跡數值沿用鐵道角色預設）。其他角色仍可逐一點選，與原創角色混隊。直接選擇「星穹鐵道敵人」會使用原本的社群資料與等級，配裝需求較高。

舊存檔只升級內容完全未改動的原創範本，包括舊選單套用的重複角色；手動修改過的單位、鐵道單位、配裝與隊伍選擇保留。存檔沿用原鍵名並記錄 `hsrTrialBalanceVersion`，之後不會重複升級。

`test/trialBalance.test.ts` 用固定的 24 個種子檢查每位可用鐵道角色換入普通戰，以及原創／鐵道試玩隊伍通過五種範本遭遇。此抽樣用於檢查試玩節奏，不表示任意配隊都有保證勝率。
