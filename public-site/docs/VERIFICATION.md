## 驗證範圍與限制

尚未實際建立新 GitHub repo 或部署到公開主機；正式公開網址、作者資料、程式授權與聯絡方式待補。

抽卡模擬器使用搬入的核心規則複本；其餘工具尚未接入研究引擎，也沒有後端資料庫。

離線 HTML 的內嵌資源已確認，瀏覽器互動以 HTTP 開啟驗證；瀏覽器工具的 URL 安全規則不允許 `file://`，因此該模式未驗證。
